## Описание

“Naiyun” — профессиональный сервис оптимизации сетевых маршрутов, поддерживающий 86 точек доступа по всему миру. Также доступны узлы с [домашними IP США](https://github.com/jdnei/naiyun#1%E7%BE%8E%E5%9B%BD), [домашними IP Гонконга](https://github.com/jdnei/naiyun#2%E9%A6%99%E6%B8%AF), [домашними IP Тайваня](https://github.com/jdnei/naiyun#3%E5%8F%B0%E6%B9%BE), [домашними IP Японии](https://github.com/jdnei/naiyun#4%E6%97%A5%E6%9C%AC), [домашними IP Южной Кореи](https://github.com/jdnei/naiyun#5%E9%9F%A9%E5%9B%BD), а также домашними IP Малайзии. Сервис предназначен для обеспечения стабильного ускоренного соединения при международной работе, зарубежном академическом поиске и просмотре мультимедийного контента.
